## 🚀 Overview

**Ashoka-AI** is an all-in-one autonomous AI creation operating system. It allows developers, designers, and creators to build full-stack websites, 2D/3D playable games, cinematic video sequences, ultra-HD visual assets, and node-based automated workflows entirely through natural language.

---

## ✨ Key Features & Engines

- 🌐 **Visual Website Studio:** Natural-language DOM compiler with instant styling, component generation, and responsive preview modes.
- 🎮 **Playable 3D Space Game:** Real-time physics engine, thruster particles, alien orb collection loop, and keyboard/touch flight controls.
- 💻 **Central 3-Panel AI IDE:** Synchronized file tree, multi-agent reasoning stream, live DOM rendering, and unit test validation.
- ⚡ **Node-Based Automations:** Visual workflow builder connecting Webhooks, AI Reasoning Agents, Databases, and Edge Notifications.
- 🎬 **Cinematic Video Studio:** Storyboard timelines, camera angle direction, voice synthesis, and 4K rendering pipelines.
- 🎨 **Ultra-HD Image Studio:** Style reference matching, multi-aspect rendering, and inpainting background removal.
- 🤖 **Autonomous Agent Fleet:** Specialized agents (Website Builder, Game Logic, Automation) with persistent long-term memory.
- 🔊 **Synthesized Web Audio FX:** In-browser audio engine delivering real-time sound feedback for clicks, generations, and success chimes.
- ⌨️ **Command Palette:** Quick universal launcher accessible via `Cmd + K` / `Ctrl + K`.
